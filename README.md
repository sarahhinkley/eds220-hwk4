## About 
This repository houses the analysis for Homework 4 in EDS 220: Working with Environmental Datasets. The analysis visualizes the Eaton and Palisades fires from January 2025 through true color imagery and false color imagery. It uses one Landsat dataset that was clipped to show part of LA County surrounding the fire perimeters and two other datasets containing the fire perimeters.

## Repository Overview
- `hwk4-task2-false-color-hinkley.ipynb`: Jupyter notebook containing all code, maps, and written interpretation.
- `data/`: All data used in the analysis. This folder is listed in .gitignore.

## About the Data

- **Landsat imagery:** Landsat 8 Collection 2 Level-2 surface reflectance data from the Microsoft Planetary Computer, using the red, green, blue, near-infrared, and shortwave infrared bands.

- **Fire perimeters:** Dissolved fire perimeters for the 2025 Palisades and Eaton fires from the County of Los Angeles.
